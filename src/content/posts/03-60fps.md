# 60 FPS není efekt, ale způsob práce

Plynulost rozhraní nevzniká jednou optimalizací. Je to výsledek mnoha malých rozhodnutí, která se násobí při každém scrollu, hoveru a interakci.

## Nejprve sleduj pohyb

Nejdřív je dobré najít moment, který působí těžce. Je problém v JavaScriptu, layoutu, paintu nebo v množství prvků, které se současně mění?

DevTools pak není poslední krok. Je to nástroj pro rychlou zpětnou vazbu během vývoje.

## Animuj správnou vrstvu

U pohybových efektů bývá užitečné dávat přednost vlastnostem, které nevyžadují neustálý přepočet layoutu.

```css
.card {
  transform: translateY(0);
  transition: transform 180ms ease;
}

.card:hover {
  transform: translateY(-2px);
}
```

Neznamená to, že `transform` vyřeší všechno. Znamená to, že animaci je potřeba navrhovat společně s rendering pipeline.

## Méně práce je větší optimalizace

Často funguje nejlépe:

- méně DOM uzlů
- menší obrázky
- méně současných animací
- méně zbytečných re-renderů
- kratší JavaScriptová cesta

### Plynulost je vlastnost systému

Když se výkon kontroluje průběžně, není potřeba na konci hasit celý dům. 60 FPS se pak stává přirozenou součástí návrhu.
